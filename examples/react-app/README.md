# React + TypeScript + Vite

This example provides a minimal setup to test the `@yoo-digital/eslint-config-react` configuration against a React + Vite project, using [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) for Fast Refresh.

## ESLint Configuration

```js
// @ts-check
import yooEslintConfigReact from '@yoo-digital/eslint-config-react';

export default [...yooEslintConfigReact];
```
